# 模型选择：把可靠性放在诚实边界里

## 结论

没有公开证据证明某个现成模型能从中文工作消息稳定识别“用户当天真实情绪”。领域、语言、个人表达习惯、讽刺、转发和工作套话都会造成偏差。模型只能生成待用户确认的文本假设。

## 默认路径

使用当前运行时支持结构化 JSON 的语言模型，输入去标识化后的本人消息时间序列，输出固定 schema；随后运行 `validate_analysis.py`。模型名不写死，部署者决定使用本地或云端提供方。

## 可选校准器

`IDEA-CCNL/Erlangshen-Roberta-330M-Sentiment` 可作为中文正负倾向的附加信号。它的公开模型卡说明在多个中文情感数据集上微调；这些基准不等于中文工作聊天的个人情绪准确率，也不覆盖细粒度状态。不得把它称为“主情绪模型”。

SMP2020-EWECT 相关模型覆盖中文微博的多类情绪，是更接近的研究方向；现有第三方权重的样本规模、许可证、维护和跨域表现不够稳定，不设为默认依赖。SemEval-2025 Task 11 也说明文本情绪检测是多语言、多标签且需要强校准的任务。

## 真正的校准

可靠性的来源顺序：

1. 用户当天自评；
2. 用户对历史结果的准确/部分准确/不准确反馈；
3. 当前文本中的明确第一人称自述；
4. 多条一致的文本线索；
5. 分类器或语言模型推断。

未经用户另行同意，不保存训练语料，不用反馈微调模型。要评估模型，使用脱敏、人工标注、按时间切分的个人验证集，并报告覆盖率、拒答率、宏平均 F1 与校准误差；不能只报告准确率。
